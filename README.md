## 🧠 Data + Applied AI

### [AskSQL | Conversational Analytics](https://github.com/Project-origination/asksql-local-llm)

**Ask business questions in plain English or French and explore the answer as data.** A local Qwen model translates natural language into SQL; the application applies read-only database access, SQL checks, and result visualizations.

`Python` · `SQLite` · `SQL validation` · `Qwen` · `LM Studio` · `Streamlit`

**[Explore AskSQL →](https://github.com/Project-origination/asksql-local-llm)**

### [AI Data Quality Agent | Trustworthy Data](https://github.com/Project-origination/ai-data-quality-agent)

**Detect data quality issues before they become business decisions.** Deterministic checks assess common anomalies and generate a quality score; a local AI layer supports interpretation and remediation guidance.

`Python` · `pandas` · `Data quality` · `Quality scoring` · `Local LLM` · `Streamlit`

**[Explore the Data Quality Agent →](https://github.com/Project-origination/ai-data-quality-agent)**

### [AI Financial Report Analyzer | Evidence-Linked Insights](https://github.com/Project-origination/ai-financial-report-analyzer)

**Turn a financial report into auditable analytics.** A report-specific prototype extracts selected statements from Berkshire Hathaway's 2025 annual report, verifies year-over-year KPIs in Python, and produces source-linked analysis. The interface distinguishes genuine AI assistance from deterministic fallback.

`Python` · `PyMuPDF` · `Financial KPIs` · `Plotly` · `Qwen` · `Source traceability`

**[Explore the Financial Report Analyzer →](https://github.com/Project-origination/ai-financial-report-analyzer)**

### My approach

```text
Business question
      ↓
Data preparation & validation
      ↓
Verified metrics / governed logic
      ↓
Dashboard, analysis or AI-assisted interface
      ↓
Clearer decisions
```

**AI can suggest; code should verify.** I prioritize transparent assumptions, reproducible metrics, and a clear distinction between model-generated content and established facts.
